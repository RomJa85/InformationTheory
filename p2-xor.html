Задание 3. Операция XOR (чётность)

Теория

Операция XOR (исключающее ИЛИ) используется во всех проверках чётности кода Хэмминга.

Правила:

  • \( 0 \oplus 0 = 0 \)
  • \( 0 \oplus 1 = 1 \)
  • \( 1 \oplus 0 = 1 \)
  • \( 1 \oplus 1 = 0 \)

XOR нескольких битов равен 1, если количество единиц нечётное, и 0, если количество единиц чётное.

$$ a_1 \oplus a_2 \oplus \ldots \oplus a_n = (a_1 + a_2 + \ldots + a_n) \bmod 2 $$

Калькулятор

Введите последовательность из нулей и единиц (пробелы и другие символы будут проигнорированы).

Примеры для проверки

  • 101 → \( 1 \oplus 0 \oplus 1 = 0 \) (чётное число единиц)
  • 1110 → \( 1 \oplus 1 \oplus 1 \oplus 0 = 1 \) (нечётное число единиц)
  • 0000 → \( 0 \)
  • 1 → \( 1 \)
